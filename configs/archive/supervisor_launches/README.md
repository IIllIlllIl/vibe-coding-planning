# Archived Supervisor Launch Identities

These YAML files are terminal, superseded, paused, or reproduction-only launch
identities. They are not current launch defaults and their presence is not
authorization to restart an experiment.

The files contain no workflow implementation. All of them call the shared
`scripts/hpc_supervisor_service.py` and `scripts/hpc_resume_loop.py`; scientific
runtime semantics remain in their separate workflow configs.
